## 5. Tech article

For dev.to, Hashnode, HackMD and maybe HackerNoon. It's about how the site is built, which is what those audiences want, and links to the book at the end.

**Title:** How I publish a free book for $0 with Bookdown, GitHub Actions and GitHub Pages

**Tags:** bookdown, githubactions, opensource, writing

---

I'm writing a free book and wanted it to live on its own domain, look good on a phone, offer PDF and EPUB downloads, and cost nothing to run. Here's the stack I ended up with. It's all open source, so you can copy it.

### Bookdown for the writing

[Bookdown](https://bookdown.org) turns a folder of R Markdown files into a website, a PDF and an EPUB from the same source. Each chapter is one `.Rmd` file, and `_bookdown.yml` lists the order. One gotcha: if you give different file lists for HTML, LaTeX and EPUB, a new chapter has to go in all three lists or it silently disappears from one format.

HTML comments are handy for notes to myself (sources, TODOs), so I strip them from the public output with Pandoc's `--strip-comments` in `_output.yml`.

### GitHub Actions to build, GitHub Pages to host

Every push to `main` runs a workflow that installs R and TeX, runs `bookdown::render_book` for each format, and deploys `_book/` to GitHub Pages. The build script writes a `CNAME` file for the custom domain. Pages gives free HTTPS once DNS points at it: four A records on the apex and a `www` CNAME to `<user>.github.io`.

Bookdown names the first page after the first chapter, so the script copies it to `index.html` so the bare domain works.

I let the PDF step fail without failing the deploy. LaTeX breaks occasionally, and I'd rather the website keep updating.

### A small post-build SEO pass

Bookdown's default meta tags repeat the book title on every page. A short Python script runs after the render and:

- writes one clean set of description, Open Graph and Twitter tags per page,
- adds canonical links,
- adds `Book` JSON-LD on the home page and `FAQPage` JSON-LD built from the FAQ page's headings,
- writes `sitemap.xml` and `robots.txt`,
- adds a `?v=<build time>` to CSS and JS links so readers never get a stale stylesheet.

### Privacy-friendly extras

- **Visit counts** from [GoatCounter](https://www.goatcounter.com), which is free for small sites and doesn't use cookies.
- **Reader suggestions:** a small "Suggest an improvement" box on each chapter page that posts to a Cloudflare Worker, which files a GitHub Issue. No database, and the token stays on the worker.
- **Share buttons** in plain JavaScript (no third-party widgets), with the phone's native share sheet when it's available.

### What it costs

The domain. Everything else is free.
