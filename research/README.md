# Research log

One file per chapter (`ch01.md`, `ch02.md` …), each with:

- **Scripture**: references and WEB text used
- **Quotes**: verbatim, with source link and date (anonymised as "a reader on r/…" in the book)
- **Pastors / teachers**: quote, speaker, link
- **Facts**: claim, source link, and how the book words it
- **Ideas**: from forums, FitXFearless, semen retention and manosphere material, marked "reported" rather than "proven"

Rules: never edit a quote's meaning, never invent a source, and keep long quotes out of the book unless the author has given permission.
