# Editorial notes

Working notes of the editing team. Contributors don't need to read these: [CONTRIBUTING.md](../CONTRIBUTING.md) has what matters.

- `STYLE.md`: the full writing brief and revision conventions.
- `BIBLE.md`: a chapter-by-chapter summary of the book, kept up to date after each editing batch.
- `ISSUES.md`, `PARKING.md`: open problems and ideas set aside.
- `OUTLINE.md`: the original plan of the book.
- `DRAFT-NOTES.md`: running notes on drafts and decisions.
- `*-REVIEW.md`, `READER-REPORT*.md`, `METHOD-CHECK.md`: reviews of the text.
- `checks/`: output of `python3 tools/editorial_checks.py`.
